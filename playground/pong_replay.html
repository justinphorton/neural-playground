Reservoir Pong replay

The neurons see only the first rows of each fall, one pulse per row. Then the paddle has to commit. Balls that hit a wall after that point are the ones a straight line gets wrong.

Toy data. These trials come from a stand-in reservoir used to test the page, not from livn. Run pong_task.py then pong_landing.py for real numbers.
